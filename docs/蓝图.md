# ctbz 蓝图（2026-09-22 版）

用途：给反审 Agent 与后续会话提供**一份可读的上下文**——愿景、已上线能力、未闭合缺口、指向文件。
维护：每次结构级变更后更新「已上线」与「缺口」两节；正文只记事实与指针，不记过程。
