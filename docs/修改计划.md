## 二、分期任务契约

**路径判据**：`仓库根` = `/Users/maolong/Betty/草台班子/ctbz-dsh`（源码，唯一可写源）；`部署副本` = `~/.agents/skills/ctbz`（**禁止手改**，只由 `部署.js` 写入）；`仓库外文件` = `~/.dsh/AGENTS.md`（不在 git、不在打包范围，须单独备份）。write-set 中仓库外路径必须逐字标注。

**每版统一六行**：目标 / write-set / 改动 / 验收表 / 机械验收 / 回滚。
**机械验收三要素**（缺一即该行判 fail）：命令（全路径 `/usr/local/bin/node`）+ 路径（文件或目录）+ 期望值（exit 码或字段断言）。
**回滚两项制**（每版同构，逐字）：
- 常规：起版基线 = 开工前 `git rev-parse HEAD`（逐字记入 `docs/验收表-<版本>.md` 首行「起版 commit: <hash>」），**不得用 tag 作基线**（v2.0.9 之后已有 `f2ae96f`/`20912d4` 等非本版 commit，按 tag 逐个 revert 会误删已上线内容）；回滚对象固定为 `git log --oneline <起版 commit>..HEAD` 列出的本版 commit，逐个 `git revert` → 跑 `部署.js` → `diff -rq skills/ctbz ~/.agents/skills/ctbz` exit 0。
- 救生艇：解包上一 tag 的包（包名取值命令：`ls ctbz-pack-*.tar.gz | sort | tail -1`）覆盖 `~/.agents/skills/ctbz/`，**跳过重跑 `部署.js`**（该脚本 `rsync -a --delete` 会用源码覆盖回来）。
- 仓库外文件：起版前 `cp ~/.dsh/AGENTS.md /tmp/AGENTS.md.bak`；回滚时 `cp /tmp/AGENTS.md.bak ~/.dsh/AGENTS.md`，再跑 `/usr/local/bin/node --test tests/主文锚点.test.mjs` 验两镜像块一致。
