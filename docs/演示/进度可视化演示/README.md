# 进度可视化演示（ctbz 2.4.0）

一个可一键复现的示例项目「电商风控策略上线」：一条命令生成演示数据，浏览器中查看总览页四视图。

## 三步走

在仓库根目录（`ctbz-dsh/`）执行：

```sh
# 1. 生成/重置演示数据（幂等，可重复运行）
node docs/演示/进度可视化演示/demo.mjs

# 2. 启动看板服务（--workspace 需绝对路径）
node skills/ctbz/scripts/dashboard serve --workspace "$(pwd)/docs/演示/进度可视化演示" --port 18999

# 3. 浏览器打开（macOS 可用 open）
open http://127.0.0.1:18999
```

> 端口 18999 被占用时换一个 `--port` 即可。演示数据落在
> `docs/演示/进度可视化演示/.ctbz-record/dashboard.json`，重跑第 1 步会整体重建。

## 演示数据内容

| 类型 | 内容 |
|---|---|
| 分组 | `plan` 策略上线（group） |
| 已完成 | `d1` 数据准备、`d2` 特征衍生、`d3` 规则引擎、`d4` 离线回测 |
| 进行中 | 无（两轮均已收尾，`d5` AB实验等待依赖就绪） |
| 受阻 | `d7` 监控告警（等待风控平台埋点权限） |
| 待开展 | `d5` AB实验、`d6` 灰度放量、`d8` 全量上线 |
| 轮次 | 2 轮（第 1 轮 d3、第 2 轮 d4，均含五字段收尾记录） |
| 待决问题 | 1 个（AB 实验流量切分比例，推荐 5% 灰度） |

## 四视图说明（总览页顶部切换）

| 视图 | 说明 |
|---|---|
| 概览 | 阶段轨 + 统计条 + 方向/问题双栏，原有默认视图 |
| 甘特 | 每节点一行条形图，按状态着色，顶部等距时间刻度 |
| 依赖图 | 按 `dependsOn` 拓扑分层；节点矩形含状态着色，箭头从依赖指向后继 |
| 里程碑 | 项目建立 / 各轮开始收尾 / 各已完成节点，按时间倒序，含相对时间 |

## 着色规则（与树图/三图一致）

| 状态 | 色值 | 含义 |
|---|---|---|
| completed | `#286746` | 已完成（深绿填充） |
| active | `#eef4ff` | 进行中（浅蓝填充） |
| blocked | `#fff4db` | 受阻（浅黄填充） |
| planned | `#f2f4f6` | 待开展（灰底默认） |
| cancelled | `#f2f4f6` + 50% 透明 | 已取消（淡出） |

补充：树图中「本轮完成」分支另用 `#dcf2de`（浅绿）标识，方便对照轮次快照。

## 轴语义（重要）

**甘特条 = 节点创建 → 最近更新时间，不是计划工期。** 当前数据模型只记录
`createdAt` / `updatedAt` 两个节点时间戳（`dashboard-store.mjs` 字段白名单），
所以条形的起点/终点表示「该节点被创建/最后一次被改动」的时刻，而非预估排期。

## 数据说明

演示数据时间戳为脚本**真实运行时间**：所有节点/轮次在脚本运行的同一分钟内生成，
甘特与里程碑上出现同日聚集、条形起点重合属预期现象，不是渲染错误。

## 疑难

- 重复运行 `demo.mjs` 前无需手删数据：脚本会先 `rm -rf .ctbz-record/`。
- 服务起不来先查端口占用；改 `--port` 后同步改浏览器地址。
- 页面停留时每 3 秒自动轮询刷新，当前所选视图不会被切回。
