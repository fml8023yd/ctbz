# 反审协议 0.0.1

1. 计划核对原始需求、目的、范围、可执行性、接口依赖、反例和验收；模块核对实现、边界、测试；集成核对完整链路、异常与回归。
2. 原生工具可用时父会话派独立 Agent，传完整契约和当前快照。评审者先独立读证据，不只复述实现者摘要。
3. 每条发现含位置、触发、证据、影响、修复或可接受风险；父会话逐条接受、举证驳回或标缺证据，不以票数覆盖反例。
4. 未知宿主、工具缺失、启动/途中失败时提示一次，父会话继续并标主进程自审；无固定厂商、人头数或旧 API 门禁，不伪称独立通过。
5. 最多三轮回修；连续两轮没有新证据换诊断路径。完成以用户原始验收和真实使用为准；模拟检查保留其证明边界。
6. 权限拒绝停止被拒动作；独立审查不新增模型费用、外部写入或文件权限。任务写集合和只读角色沿用共享契约。

运行字段见 [派发契约](派发.md)，模式与授权见 [统一工作流](unified-workflow.md)。
