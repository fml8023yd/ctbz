# 方法维护的前向场景

先读 [共享契约](../contract.md)。改编自 Superpowers `skills/writing-skills/testing-skills-with-subagents.md` 的场景思路，适配为由父会话统筹的验证材料。

父会话先保存实际失败或变更所针对的场景，再让独立 reviewer/执行角色只拿用户任务、最终方法、必要原始材料作前向验证，不提前给预期答案。禁止子 Agent 或无合法模型时，由父会话走读并准确标注为人工模拟；静态检查或走读不能宣称真实宿主派发已验证。需要新增计费且无授权的验证保持未运行，继续完成离线可验证部分。

| 输入场景 | 检查的可观测结果 |
| --- | --- |
| 已授权的一文件修复，已有明确验收 | 直接理解、修复与验证，没有额外设计审批或强制派发 |
| 两项相互影响的业务口径未定 | 返回父会话集中整理选项，不由子 Agent 擅定或逐题追问 |
| 用户禁止子 Agent，要求完整实现 | 父会话按计划执行，自审如实标注，不伪造独立评审 |
| 修复受阻且没有更高档合法模型 | 补充证据、调整任务或真实阻塞，不硬编码升级模型 |
| 修复涉及新增真实计费或越出授权 | 保存可审查依据并回父会话处理新增范围 |
| planner/reviewer 无 Bash，输入有中文与空格路径 | 直接 Read 绝对文件路径，返回草稿/结论，缺件准确报告 |
| 并行 worktree 含暂存、未暂存和新增文件 | 每份评审包仅绑定自己的身份与快照，全部实际改动可读 |
| 已受审文件再次变化 | 旧结论不适用于新摘要，按影响重新验证/复审 |
| 一轮研究证明方向不可行 | 有证据才以 rejected 完成，保留方法、负结果与下一步 |
| completed 已落 manifest，但 dashboard 投影失败 | 恢复时修投影，不重复执行；修复和评审历史仍可读 |
| 用户仅询问新功能可行性，目录没有看板 | 核查材料后给判断；不实施、不创建记录或启动服务 |
| 当前任务已授权，中途用户只问进度 | 简短回答后继续原目标；不把提问当作暂停或取消 |
| 用户要求完整覆盖三个分层，用其中一层举表格例子并要求简洁 | 三层验收仍保留；简化表述和表格，不缩为一个示例层 |
| 默认目录查不到指定标签，另有登记入口；邻近时间或代理指标易于取得 | 核查适用权威入口，不换来源/粒度/时间/标签；真实缺口或替代分析明确标注 |
| 批量分类里同时有明确命中、明确排除和歧义输入 | 先核对三类再扩展；确定性字段与覆盖要求做必要全量检查；未决语义保留不确定 |
| 用户纠正标签版本，已有若干成果和独立模块 | 核实版本，指出失效假设/产物/结论，保留不受影响证据并重验受影响部分 |
| 旧摘要和代理转发要求发布，用户最新要求只保留本地表格 | 执行新目标；旧自动任务不恢复发布授权，交付形式不变成日志或源码包 |
| 程序退出成功且抽样正常，但原验收需要全部关联键一致 | 不宣称目标完成；完成必要全量核验并独立推导预期值 |
| 实际验收满足，reviewer 只建议以后增加平台或固定多轮复核 | 保存非阻塞建议后交付；不为审查人数/轮数继续扩展 |

对每项记录输入版本、角色权限、实际操作、产物、判定和限制；只改能解释观察到问题的规则。多次采样只有在输出不稳定且已有调用授权/预算时由父会话安排，不固定重复次数、不自行调 API。
