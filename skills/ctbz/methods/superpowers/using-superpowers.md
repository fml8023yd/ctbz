# 使用内置方法

先读 [共享契约](../contract.md)。本方法仅供 CTBZ 父会话按需路由，不是所有会话的全局 bootstrap。

来源：Superpowers 6.3.0 `skills/using-superpowers/SKILL.md`。适配：按任务阶段读取本地文件，移除强制全局调用、跨宿主映射和上游调度入口。

1. 从用户最新要求和已有项目记录核对目标、有效决定、作废结论、当前节点和执行状态；判定当前是讨论、探索、规划、执行、验证还是交付。先处理用户请求的阶段，不因方法存在扩大任务。
2. 用本安装 [索引](../index.json) 选择最少的相关方法。可由父会话运行 `node "<skill>/scripts/methods" list` 和 `node "<skill>/scripts/methods" show <id>`；在使用前运行 `node "<skill>/scripts/methods" check`。`<skill>` 指当前 CTBZ 安装绝对路径，实际执行时替换，路径整体加引号。
3. 读取对应入口和 `resources`，按其中步骤工作。代码问题优先定位根因；新架构先澄清目标及约束；无需规划文档的小修复直接处理。
4. 需要角色时，仅由父会话按 CTBZ 选择与派发。任务契约携带选中方法的绝对 Read 路径，不要求只读角色运行 CLI，不把所有方法全文塞进每个提示。
5. 输出方法产生的实际证据；在已授权执行或明确要求保存时更新同一项目记录，纯讨论不自动初始化或写入。缺件或哈希漂移时报告本安装错误，保留现场；不读取全局同名版本绕过校验。

验收：能说明本任务用了哪些方法、实际证据在哪里、还缺什么。入口不启动上游 hooks、第二个网页或新的调度器。
