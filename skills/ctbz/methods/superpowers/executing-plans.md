# 父会话执行计划

先读 [共享契约](../contract.md)。仅 parent 使用；适用于主会话直接执行、禁子 Agent、未初始化及需要顺序处理的任务，不要求另开会话。

来源：Superpowers 6.3.0 `skills/executing-plans/SKILL.md`。适配：保留检查点与验收，移除必须派发、固定工作树或等待用户逐批批准的要求。

1. 读取规格、计划和当前项目/执行记录，核对已完成项、正在执行项、待决事项与依赖。继承已证实进度，不重放完成任务。
2. 确认当前授权工作目录、write-set、基线和验证方式。已在合适隔离工作区则复用；需要并行写入隔离时由父会话按 [worktree 方法](using-git-worktrees.md) 准备。没有团队 manifest 的父会话任务用 parent-only 项目材料记录。
3. 执行当前就绪任务，在真实开始与检查点更新项目状态。代码先写或补足能发现目标缺陷的检查，再实现并验证；遇到异常用 [系统调试](systematic-debugging.md)。技术计划与事实不符时在已授权范围修订并记录原因，涉及业务/费用/权限则回集中澄清流程。
4. 对照验收逐项收集证据，按 [评审方法](requesting-code-review.md) 检查成果。禁子 Agent 时父会话自审，明确独立评审未运行；不以缺少团队为理由卡住已授权小任务，也不冒充独立结论。
5. 保存任务结果与未解决事项，推进下一项就绪任务。全部任务达到验收后走 [完成验证](verification-before-completion.md) 与 [集成收尾](finishing-a-development-branch.md)。只完成 run 时不宣布整个项目完成。

阻塞时记录失败命令、已排除假设、缺件及最小下一步；预算耗尽或必要前提不满足就暂停相应工作，独立已授权事项可继续。验收失败不能用勾选计划或乐观报告替代。
